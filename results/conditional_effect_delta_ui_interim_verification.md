# 조건부 룬 효과·DPS 델타 로컬 UI 중간 검증

## 확인 시점 및 환경

| 항목 | 값 |
| --- | --- |
| 확인 시점 | 2026-08-14 GMT+9 |
| 화면 | 로컬 개발 서버 `http://127.0.0.1:5173/MobiNogi-fighter-season2/` |
| 확인 경로 | 종합 계산기 → 전투 설정 플로팅 패널 |
| 장착 룬 | 타오르는 영광, 흐릿한 형상, 승전, 승천+ |

## 실제 렌더링 확인 결과

| 항목 | 결과 |
| --- | --- |
| 타오르는 영광 카드 | 원문 기반 설명, 기본 가동률 13%, step 1 슬라이더가 표시됨 |
| 효과별 카드 키 | 룬 ID·효과 ID 기반 카드로 렌더링됨 |
| 기존 룬 가동률 카드 | 흐릿한 형상 및 승전의 기존 카드가 유지됨 |
| 1차 발견 결함 | 타오르는 영광의 조건부공증이 계산 결과에 반영되어도 카드의 ‘현재 계산 DPS 배율’이 0.00%로 표시됨 |
| 2차 발견 결함 | 효과의 내부 5초 불씨 생성 주기가 조건부공증 가동률을 100%로 잘못 계산해 카드에 +24.38%로 과대 표시됨 |
| 최종 재검증 | 실전 검수 기본 가동률 13%를 강제 우선하도록 수정했고, 실제 카드에 **DPS 배율 +4.02% · 직접/도트 0/초**가 표시됨 |

> 원인과 수정: 정적 조건부 효과는 처음에 시간축 결과만 보존해 UI가 0.00%를 표시했다. 이후 내부 5초 불씨 생성 주기를 조건부공증 가동률로 오인해 +24.38%가 표시되는 과대 반영을 발견했다. 이제 `forceDefaultUptime` 계약으로 최신 검수 기본값 13%가 시간 주기보다 우선하고, 효과별 평균 스탯과 동일 기준의 DPS 배율을 함께 보존한다. 카드의 +4.02%는 **해당 효과만 현재 전체 기준에 추가했을 때의 배율**이며, 여러 효과 합산 후 최종 DPS 차이는 결과 패널과 함께 검증한다.

이 검증은 UI 연결 상태를 확인한 중간 기록이며, 최종 품질 관문·공개 배포 검증은 후속 단계에서 다시 실행한다.
