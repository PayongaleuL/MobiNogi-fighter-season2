# P2-C 실제 렌더링 검증 기록

## 2026-08-13 · 연결된 사용자 브라우저

로컬 Vite 미리보기 `http://localhost:5173/MobiNogi-fighter-season2/`를 실제 연결 브라우저에서 열었다. 데스크톱 렌더링에서 다음을 확인했다.

| 확인 항목 | 결과 |
| --- | --- |
| 기본 스펙 입력 | `마도저항` 숫자 입력과 슬라이더가 렌더링됨 |
| 시즌2 대상 목록 | 함선·티르코네일 허수아비, 칼드레드·데스펠·테로사 매우 어려움, 카브락 입문이 표시됨 |
| 레거시 대상 | `어비스 지옥2`가 대상 선택 목록에 없음 |
| 대상 메타데이터 | 필요 마도저항·마도압력과 방어도·치명타저항 미확정 안내가 렌더링됨 |
| DPS 요약 | 적용 공격력, 마도저항/압력, 마도저항 최종피해, 룬 공격력 가산, 치명타·추가타 지표가 렌더링됨 |

후속 단계에서 카브락 입문 선택과 2,000 초과 마도저항의 `+14.6%` 표시·DPS 갱신을 직접 조작해 추가 확인한다.

## 카브락 입문 선택 확인

대상 선택에서 `카브락 · 입문`을 실제로 선택한 뒤 화면이 다음과 같이 갱신됨을 확인했다.

| 확인 항목 | 결과 |
| --- | --- |
| 대상 선택값 | `카브락 · 입문 · 필요 저항 2,000 / 압력 2,500` |
| 대상 안내 | `필요 마도저항 2,000 / 마도압력 2,500` 표시 |
| 공식 보정 안내 | 초과분은 공식 예시점 보간으로 최종피해 반영, 미달 정량 계수는 미적용이라고 표시 |
| 불확정성 안내 | `방어도·치명타저항: P2-B 로그만으로 미확정` 표시 |
| 출처 연결 | 넥슨 공식 수치 근거 링크가 표시 |

## 마도저항 = 마도압력 기준 확인

카브락 입문 선택 상태에서 실제 입력을 `2,500`으로 변경했다. DPS 요약이 `마도저항 / 압력 2,500 / 2,500`, `마도저항 최종피해 +0.0%`로 즉시 갱신됐다. 이는 초과분이 0일 때 추가 최종피해가 없다는 코어 계약과 일치한다.

## 마도저항 2,000 초과 직접 검증

카브락 입문 선택 상태에서 마도저항을 `2,500`에서 `4,500`으로 변경했다. 실제 DPS 요약은 `359,132 DPS`에서 `411,565 DPS`로 갱신됐고, 요약 카드에 `마도저항 / 압력 4,500 / 2,500`, `마도저항 최종피해 +14.6%`가 렌더링됐다. 산출 비율은 약 1.146으로 공식 2,000 초과 예시와 일치한다.
