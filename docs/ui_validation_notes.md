# UI 검증 기록

## 브라우저 상호작용 확인

- 좌측의 세로 `조건부 설정` 탭을 클릭하면 360px 폭의 좌측 설정 바가 열렸다.
- 설정 바에는 조건부 룬 가동률과 밤의 축복 가동률이 표시되었고, 조건부 룬이 없는 경우에도 밤의 축복 조정 카드가 유지되었다.
- Escape 키 입력 후 설정 바의 `aria-hidden` 상태가 닫힘으로 전환되었으며, 다시 세로 탭만 노출되었다.
- 실전 DPS 결과는 우측 상단의 일반 문서 흐름에 배치되었고, 스크롤 추적 스타일을 사용하지 않았다.

## 최종 확장 회귀 검사

장착 흐름에서 무기 슬롯에 `눈부신 잔영`을 장착한 뒤 룬 교정실의 `장착 중인 룬` 필터를 적용했다. 필터 결과 첫 행과 고정 첫 열은 모두 에메랄드 상태 토큰(`bg-emerald-500/8`, `border-emerald-500`, `bg-emerald-500/10`)을 포함하는 것으로 검증되었다.

확장된 UI 회귀 스크립트는 2560×1440·1440×1050·390×844에서 모두 통과했다. 검증 범위는 DPS 즉시 갱신, DPS 영역의 sticky/fixed 부재, 보석 탭 전환, 테마 전환, 조건부 설정 열기·바깥 클릭 닫기·Escape 닫기, 모바일 접이식 설정, 장착 룬의 에메랄드 상태 색, 초광폭 첫 화면 핵심 결과 영역 노출이다.
