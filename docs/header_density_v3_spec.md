# 상단 헤더 밀도 개선 실행 명세

## 진단

현재 상단은 제목 아래의 설명문, 넉넉한 컨테이너 상·하단 패딩, 헤더 하단 여백, 헤더와 본문 사이의 간격이 연속으로 누적된다. 또한 우측 탐색 탭에는 아이콘과 비교적 큰 내부 여백이 함께 적용되어, 시안보다 제목·테마 전환·탭 네비게이션이 낮은 위치에 나타난다. 이 누적 높이 때문에 종합 계산기 본문의 첫 카드와 우측 결과·룬 보드가 필요 이상으로 아래에서 시작한다.

## 구현 기준

| 구역 | 시안 정합성 기준 | 구현 방침 |
| --- | --- | --- |
| 외부 작업공간 | 제목이 상단 여백에 밀착 | 초광폭·데스크톱의 상단 패딩과 컨테이너 간격을 축소한다. |
| 제목 영역 | 제목과 탐색이 단일 헤더 행에 배치 | 데스크톱에서 설명문을 숨기고 제목의 줄 높이·여백을 줄인다. 모바일에서는 보조 설명을 유지한다. |
| 테마·탭 영역 | UI THEME, 토글, 4개 텍스트 탭이 제목과 같은 상단 행에 배치 | 우측 제어부를 한 줄로 정렬하고, 탭 아이콘을 제거해 시안의 텍스트 중심 탐색 구조로 맞춘다. |
| 헤더 하단 | 얇은 경계선 바로 아래에서 콘텐츠 시작 | 하단 패딩과 본문 시작 간격을 축소한다. |
| 반응형 | 작은 화면의 조작성을 보존 | `lg` 미만에서는 제목·제어부를 자연스럽게 줄바꿈하고 터치 영역을 유지한다. |
| 기능 보존 | 계산 및 탭 이동에 영향 없음 | 계산 엔진·스킬 계수·입력 상태·탭 상태는 변경하지 않는다. |

## 검증 기준

2560×1440 및 1440×1050에서 제목·테마·탭이 상단 한 행에 들어가고, 종합 계산기의 핵심 첫 카드가 기존보다 위에서 시작해야 한다. 390×844에서는 수평 스크롤이 없어야 하며, 테마 전환·탭 전환·전투 설정 바·DPS 갱신 동작이 유지되어야 한다.

## 구현 중간 검증

로컬 미리보기에서 제목·UI THEME·토글·4개 텍스트 탭이 데스크톱 상단 한 행에 정렬되었고, 제목 아래의 보조 설명은 데스크톱에서 제거되었다. 외부 패딩, 헤더 하단 패딩, 본문 시작 간격을 줄인 결과 종합 계산기의 첫 카드와 우측 DPS 결과 보드가 기존 배포 화면보다 위에서 시작한다. 첫 화면 아래 잔여 스크롤 높이는 308px에서 264px로 줄었다.
루트 컨테이너의 데스크톱 상단 여백도 함께 축소한 뒤 다시 확인했다. 제목·테마·탭은 시안처럼 페이지 상단에 밀착됐고, 종합 계산기의 본문 시작 위치와 우측 결과·룬·세부 연산 보드가 추가로 위로 이동했다. 브라우저 기준 첫 화면 아래 잔여 스크롤 높이는 264px에서 216px로 더 줄었다.
자동 UI 회귀는 2560×1440, 1440×1050, 390×844에서 모두 통과했다. 새 상단 밀착 기준, 수평 스크롤 부재, DPS 비고정, 테마·탭 전환, 전투 설정 바, 스탠스 선택, 룬 상태색 및 입력 DPS 갱신이 함께 확인됐다.

## 품질 관문 결과

`npm run verify`가 통과했다. 린트는 오류 0건(기존 경고 24건), 테스트는 58개 모두 통과했고 커버리지는 Statements 99.13%, Branches 95.90%, Functions 100%, Lines 99.60%였다. 프로덕션 빌드와 기본 E2E도 성공했다. 최신 참조 프리셋 5건의 편차는 -4.36%, +0.23%, +4.40%, -1.05%, +2.08%, 전체 평균 +0.26%로 기준을 만족했고 마을 공격력 60,607 입력의 적용 공격력 105,638 계약이 유지됐다.
