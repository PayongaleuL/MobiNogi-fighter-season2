# 격투가 계산기 시즌 2 UX/UI 재설계안

## 설계 목표

이번 재설계의 목적은 계산 조건을 빠르게 완성하고, 변경된 조건이 **최종 DPS**에 미치는 결과를 즉시 검증할 수 있게 만드는 것이다. 기존의 능력치·룬·전투 조건·결과 상세 정보와 계산 상태는 유지한다. 특히 `calculateDPS`의 입력 구조, 계산 결과, 저장 프리셋 형식은 변경하지 않으며 화면 배치와 시각적 위계만 개선한다.

| 사용자 과업 | 기존 경험의 마찰 | 개선 원칙 |
| --- | --- | --- |
| 기본 스펙 입력 | 숫자 입력과 슬라이더가 반복되어 핵심값을 빠르게 훑기 어렵다. | 입력 카드를 군집화하고, 라벨·수치·효율 보조값의 위계를 고정한다. |
| 전투 가정 설정 | 보스, 시간, 사이클, 스탠스가 화면에 흩어져 있다. | 영향도가 높은 전투 가정을 하나의 독립 단계로 묶고 명확한 보조 설명을 둔다. |
| 룬 세팅 | 10개의 슬롯이 동일하게 보여 장착 현황과 완료도를 인지하기 어렵다. | 부위 유형별 구획을 강화하고 완료 상태를 요약 지표로 노출한다. |
| DPS 검증 | 최종 결과가 입력 영역 아래에 있어 스크롤과 시선 이동이 크다. | 데스크톱에서는 우측 결과 패널을 상단에, 모바일에서는 결과 카드를 우선 배치한다. |

## 새로운 정보 구조

종합 계산기 탭은 **기본 스펙**, **전투 가정**, **룬 세팅**, **결과 검증**의 네 영역으로 구성한다. 넓은 화면에서는 왼쪽 열에 입력 과정을, 오른쪽 열의 상단에는 즉시 확인 가능한 결과 패널을 둔다. 룬 세팅은 우측에서 결과 패널 뒤에 이어지며, 프리셋 비교는 결과 상세의 마지막에 배치한다. 좁은 화면에서는 결과 카드가 기본 스펙 직후에 오도록 하여 사용자가 입력값과 DPS를 반복적으로 비교할 수 있게 한다.

| 영역 | 시각적 처리 | UX 효과 |
| --- | --- | --- |
| 진행 안내 | 상단의 작은 3단계 안내와 완료 카운트 | 처음 사용하는 이용자가 입력 순서를 파악한다. |
| DPS 요약 | 대비가 높은 결과 카드, 핵심 수치 1개, 보조 지표 4개 | 결과의 위치와 핵심 KPI를 즉시 인지한다. |
| 전투 가정 | 보스·시간·사이클을 하나의 `실전 시뮬레이션` 카드로 통합 | 실제 DPS의 전제조건을 빠르게 검토한다. |
| 룬 세팅 | 슬롯 진행 상태와 부위 구분을 강화 | 누락된 룬 슬롯을 찾기 쉬워진다. |
| 세부 연산 | 평상시/궁극기 카드를 비교 가능한 수치 행으로 표준화 | 계산 결과를 투명하게 검증한다. |

## 시각 시스템과 반응형 원칙

기존의 따뜻한 아이보리·오렌지 팔레트와 다크 모드 토큰은 유지한다. 카드 간 대비는 배경색 변화보다 여백, 테두리, 제목의 크기 차이로 만든다. 핵심 결과에는 오렌지를 사용하되, 공격력·치명타·추가타 등 보조 지표에는 절제된 색상 구분을 사용한다. 모든 입력 요소는 키보드 포커스가 명확해야 하며, 작은 화면에서는 가로 스크롤 없이 한 열로 재배치되어야 한다.

> 계산 신뢰성은 표현보다 우선한다. 이번 작업은 계산 함수, 데이터 모델, 입력 변환, 프리셋 저장 구조를 수정하지 않는다.
