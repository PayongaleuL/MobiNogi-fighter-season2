# 시즌2 룬 데이터 계약 및 반영 기록

## 데이터 권위와 범위

시즌2 격투가 룬의 읽기 전용 권위 원본은 `results/260814_룬설명목록.md`이며, 승인된 SHA-256은 `A86E44F39200A2872DD15A9C8B2C577B2EAA052F6BF9476B5A2254D61908B93A`다. 현재 데이터베이스 `src/data/runes.json`은 88개 룬과 동일한 이름 집합을 유지한다. 49개 행의 과거 가동률 검수 워크북은 일부 룬의 수동 검수 기록으로 사용하되, 현재 JSON에 수동 보정된 값이 있을 경우 현재 JSON을 계산 기준으로 사용한다.

| 구분 | 적용 규칙 |
|---|---|
| 상시 공격력 | `공격력%`는 마을 공격력에 한 번만 가산하며 가동률과 초월 배율을 적용하지 않는다. |
| 조건부 공격력 | `조건부공증%`로 분리하고 효과별 기본 가동률 또는 사용자 입력 가동률을 적용한다. |
| 조건부 효과 키 | `룬명:효과ID` 수동 가동률이 가장 우선하며, 기존 `룬명` 가동률 입력과 호환된다. |
| 밤의 축복 | `밤축_` 접두사 효과는 효과 가동률과 밤의 축복 가동률을 함께 적용한다. |
| 세공 | `gemCalculator.js`의 8개 스킬 태그 피해·쿨감과 특수 보석 최종 피해를 기존 계산 경로로 유지한다. |
| 룬 교정실 | 기존 수동 보정값을 보존하고 마스터 목록에만 있는 누락 룬만 동기화한다. |

## 명시 보정
