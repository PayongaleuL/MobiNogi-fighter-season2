# 시즌2 룬·세공·교정실 DPS 반영 구현 보고서

## 구현 범위

시즌2 룬 설명 원본과 현재 페이지 데이터를 전수 대조했다. `runes.json`의 88개 룬은 검수 완료 설명 목록과 동일한 이름 집합을 유지하며, 룬의 기존 수동 보정 수치·가동률을 파서 자동 추출값보다 우선하도록 명시했다. 교정실의 기존 전체 초기화는 사용자 보정값을 덮어쓸 수 있었으므로, 마스터에만 있는 누락 룬을 추가하는 안전 동기화로 변경했다.

타오르는 영광은 상시 공격력 23.5%와 궁극기 불씨름 12중첩 소모 효과를 분리했다. 후자는 조건부 공격력 42%, 기본 가동률 13%로 모델링했으며, 효과별 가동률 키와 기존 룬 단위 가동률 입력을 모두 지원한다. 상시 `공격력%`는 가동률과 초월 배율을 적용하지 않고, `조건부공증%`만 효과 가동률에 따라 적용한다.

| 검증 항목 | 결과 |
|---|---|
| 룬 데이터 계약 | 88개 고유 룬, 모든 스탯 숫자형·설명 존재 확인 |
| 전수 계산 회귀 | 88개 각각 단독 선택 시 유한 DPS·적용 공격력 산출 확인 |
| 흐릿한 형상 | 기본 가동률 70% 고정 |
| 타오르는 영광 | 상시 공격력 23.5% + 조건부 공격력 42% × 기본 가동률 13% |
| 세공 경로 | 8개 스킬 태그 피해·쿨감과 특수 보석 최종 피해 계산 경로 유지 |

## 품질·UI 검증

`npm run lint`는 신규 오류 없이 통과했다. `npm run test:coverage`는 13개 파일·63개 테스트를 통과했고 Statements 99.15%, Branches 95.63%, Functions 100%, Lines 99.61%를 기록했다. `npm run build`도 성공했다. 브라우저 UX/UI 검증에서는 ultrawide, desktop, mobile에서 수평 오버플로 없음, DPS 즉시 갱신, 보석 탭 표시, 장착 룬 시각화, 다크 테마, 조건부·스탠스 설정, 첫 화면 검사를 모두 통과했다.
