## 문제와 원인

장착 중인 룬 상세 효과 사전은 `RuneSelector` 내부의 독자적인 텍스트 정제 로직을 사용했다. 이 경로는 소수점·단위·조건어가 배열 줄 경계에서 끊기는 경우를 충분히 결합하지 못했고, 정상 조건어를 노이즈로 제거하는 과거 규칙도 포함하고 있었다. 룬 선택 모달만 확인한 이전 검증은 이 상세 사전 경로를 놓쳤다.

| 사용자 보고 사례 | 결함 표시 | P0 정상 표시 |
|---|---|---|
| 타오르는 영광 | `23.` / 단독 `5%`, 단독 `시 5초마다`, `3.` / 단독 `5%` | `23.5%`, `전투 시 5초마다`, `3.5%` |
| 흐릿한 형상 | 단독 `시 1초마다 침식 수치가 5 증가` | `전투 시 1초마다 침식 수치가 5 증가한다` |
| 승전 | `51020명`, `3%6%12%` | `5/10/20명`, `3%/6%/12%` |
| 승천+ | `단계마다 1.` / 단독 `5%` | `단계마다 1.5% 증가한다` |

## 구현

`src/utils/runeTextNormalizer.js`를 추가했다. 이 모듈은 React·DOM·localStorage에 의존하지 않는 표시 전용 순수 유틸리티다. 숫자·소수점·단위·명시된 `/` 단계 시퀀스를 문장 분리 전에 결합하고, 메타데이터 전용 줄을 제외한다. 근거 없는 숫자나 게임 수치를 추정하지 않는다.

`RuneSelector`는 모달과 장착 상세 사전에서 같은 `normalizeRuneText()` 결과를 사용한다. 따라서 두 화면의 텍스트 처리 경로가 다시 갈라지지 않는다. 88개 데이터 전수 검사는 고아 조건어, 고아 퍼센트, 고아 소수점, 병합된 인원/퍼센트 시퀀스, 대체문자를 탐지한다.

추가로 전수 감사에서 `눈부신 잔영`의 `8,341%의1 피해` OCR 잔재를 발견해 표시 전용으로 `8,341%의 피해`로 정정했다. 룬의 계산 스탯은 변경하지 않았다.
