# 시안 정합성 UI 재설계 명세 v2

## 목표

첨부된 종합 계산기·보석 세공실·룬 교정실·인장 설정실 시안의 정보 위계와 초광폭 첫 화면 밀도를 구현한다. 계산 엔진과 데이터 계약은 변경하지 않으며, 입력·상태·결과의 표현 계층만 수정한다.

## 현재 진단

현재 종합 계산기는 `기본 스펙`, `스킬별 스탠스`, `전투 상황`을 좌측에서 연속 카드로 표시한다. 기본 스펙 내부의 장문 계약 설명, 독립형 스킬 개조, 추가 인챈트, 시즌 패시브 카드는 세로 점유를 확대한다. 결과적으로 1440px 및 2560px 화면에서 룬 세팅·세부 연산·프리셋 비교가 같은 첫 화면에 안정적으로 들어오지 않는다. 또한 스킬 스탠스는 DPS 필수 설정이지만 부가 설정과 별도 카드로 표시되어 시안의 밀도와 다르다.

| 요구 영역 | 시안 기준 | 구현 기준 |
| --- | --- | --- |
| 제목·탭 | 제목은 좌측, 탭은 우측의 얇은 한 줄 헤더 | 헤더 높이·패딩·탭 대비를 축소하고 Quick flow 스트립은 제거 |
| 종합 계산기 좌측 | 기본 스펙, 시즌 패시브, 최종뎀, 전투 조건만 짧은 카드로 배치 | 스킬 스탠스와 조건부 가동률은 좌측 설정 바로 이동 |
| 종합 계산기 우측 | DPS 결과 → 5×2 룬 → 세부 연산·프리셋이 첫 화면에 노출 | 카드의 제목·보조문·여백을 더 압축하고 하단 두 영역을 2열로 배치 |
| 플로팅 바 | 좌측에서 열리는 보조 계산 설정 | 조건부 룬 가동률, 밤의 축복, 스킬별 스탠스 5개를 단일 패널에 통합 |
| 보석 세공실 | 6개 핵심 합산·특수 보석·장비군 카드가 한 대시보드 | 설명과 슬롯 카드의 수직 여백을 축소하고 시안 순서 유지 |
| 룬 교정실 | 4개 요약, 단일 가이드, 필터, 고밀도 테이블 | 행 상태 배경을 유지하고 상단 카드·필터 간격을 축소 |
| 인장 설정실 | 4개 요약, 5×2 슬롯, 두 개의 하단 부가 능력 설정 | 설명과 슬롯 여백을 축소하고 2560px 첫 화면에 5×2가 표시되게 정렬 |

## 구현 규칙

1. `calculator.js`, 스킬 계수, 룬·보석·인장 계산기 및 마을 공격력 계약은 수정하지 않는다.
2. 스킬 스탠스의 상태와 콜백은 `Calculator.jsx`에서 유지하고, 표현 컴포넌트만 `ConditionalSettingsSidebar`로 이동한다.
3. 데스크톱 설정 바는 Escape·바깥 클릭으로 닫히고, 모바일에서는 접이식 `details` 영역에 조건부 설정과 스탠스를 함께 표시한다.
4. 실전 DPS 결과는 항상 일반 문서 흐름이며 `sticky`·`fixed`를 사용하지 않는다.
5. 2560×1440에서 종합 계산기의 결과·룬 5×2·세부 연산·프리셋 제목이 첫 화면에 노출되어야 한다.
6. 시안의 아이보리·오렌지 테마, Pretendard 전역 폰트 및 라이트·다크 테마 동작을 유지한다.
7. UI 회귀 검사에는 스탠스 설정 바 열기, 5개 셀렉트 노출 및 스탠스 변경 후 DPS 갱신을 추가한다.

### 플로팅 바 세부 규칙

데스크톱 플로팅 바의 상단에는 `전투 보조 설정` 제목과 닫기 버튼을 배치하고, 이어서 `스킬 스탠스`와 `조건부 버프·가동률`을 명확한 구획으로 표시한다. 스탠스 5개는 1열 고밀도 선택 행으로 제공하되 각 행에 스킬 번호·이름·선택값을 함께 표시한다. 스탠스 섹션은 조건부 룬이 없어도 항상 보이며, 조건부 섹션은 장착 룬에 따라 동적으로 확장된다. 모바일 `details`에도 두 섹션을 같은 순서로 넣는다.

### 탭별 첫 화면 정렬 규칙

보석 세공실은 제목 아래에 요약 6개와 특수 보석 3개 보드를 한 행으로 유지하고, 완성 권장 안내는 한 줄 높이로 축소한다. 장비군 카드의 내부 패딩·소켓 카드 여백·옵션 토글 높이를 줄여 무기/장신구와 방어구/엠블럼 블록이 시안처럼 첫 화면에 함께 보이도록 한다.

룬 교정실은 제목·복원·복사 버튼, 4개 통계, 단일 안내줄, 필터줄, 테이블 헤더 순서를 시안처럼 유지한다. 필터는 한 줄에 유지하고 테이블의 행 높이·수치 입력 높이를 줄인다. 기존 장착·누락·수정·일치 상태 색의 우선순위는 그대로 유지한다.

인장 설정실은 제목·설명, 4개 환산 요약, 5×2 인장 슬롯을 한 화면의 상단 그리드로 배치한다. 부가 능력치 패널은 그 아래 2열에 두며, 카드의 중복 설명과 큰 세로 여백은 제거한다.

## 브라우저 중간 검증

로컬 미리보기에서 제목·탭은 얇은 한 줄 헤더로 축소되었고, 종합 계산기 본문에는 더 이상 인라인 스탠스 카드가 표시되지 않았다. 좌측 `전투 설정` 탭을 열면 스킬별 스탠스 5개 선택 행과 조건부 룬·밤의 축복 설정이 같은 바에 표시되었다. 우측에는 일반 문서 흐름의 DPS 결과, 5×2 룬 슬롯, 세부 연산 보드와 프리셋 보드가 순서대로 유지되었다. 1440px 기준 세부 연산과 프리셋의 제목은 첫 화면에 노출되며, 2xl 이상에서는 두 보드를 한 행으로 배치해 시안의 초광폭 화면 밀도를 맞춘다.
전투 설정 바에서 1번 차징 피스트의 스탠스를 `충돌`로 변경했으며, 설정 바를 연 상태에서도 우측 결과 보드가 문서 흐름의 원래 위치에 유지되었다. Escape 키 입력 뒤 패널은 즉시 닫혔고 좌측 세로 탭만 남았다. 이 동작은 자동 UI 회귀 시나리오에도 반영한다.
보석 세공실은 상단의 세공 핵심값 8개, 특수 보석 효과, 완성 권장 안내를 한 행으로 정리한 뒤 무기·장신구·엠블럼·방어구 세공 보드를 고밀도 그리드에 표시했다. 룬 스탯 교정실은 제목·동기화 상태·복원/복사·5개 요약 지표·검색 및 두 필터·상태색 테이블의 첫 행을 첫 화면에 노출했으며, 장착 상태는 에메랄드 행 배경 규칙을 그대로 유지한다.
인장 설정실은 제목과 4개 환산 요약 보드 아래에 무기·목걸이·반지·엠블럼·방어구 10개 슬롯을 5×2로 배치했다. 기본 미장착 상태에서는 해당 탭의 전체 설정 보드가 첫 화면 안에 모두 들어오는 것을 확인했다.
자동 UI 회귀는 2560×1440, 1440×1050, 390×844에서 모두 통과했다. 세 화면에서 수평 스크롤이 없고, DPS는 일반 문서 흐름에 있으며 sticky/fixed 조상이 없었다. 새 전투 설정 바의 열기·바깥 영역 닫기·Escape 닫기와 5개 스탠스 선택 상태 변경, 보석 탭 전환, 룬 장착 에메랄드 행, 테마 전환, 입력 DPS 갱신을 확인했다.

## 품질 관문 결과

`npm run verify`가 통과했다. 린트는 오류 0건(기존 경고 25건), 테스트는 58개 모두 통과했고 커버리지는 Statements 99.13%, Branches 95.90%, Functions 100%, Lines 99.60%였다. 프로덕션 빌드와 기본 E2E도 성공했다. 최신 참조 프리셋 5건의 편차는 각각 -4.36%, +0.23%, +4.40%, -1.05%, +2.08%, 전체 평균 +0.26%로 모두 기준을 만족했고 60,607 마을 공격력 입력의 적용 공격력 105,638 계약도 유지되었다.
