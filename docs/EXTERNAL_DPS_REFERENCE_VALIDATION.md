# 함선 허수아비 외부 DPS 기준 대조 검증

**검증일:** 2026-08-12 KST

**검증 대상:** 비식별 함선 허수아비 기준 기록 5건 및 배포 계산기의 예시 프리셋 5건

**판정 목적:** 기존 구글 스프레드시트와 동일한 공격력 입력 계약을 보장하고, 약승열·전승강의 실제 측정 DPS 평균과 계산 결과의 편차를 검증한다.

> **확정 입력 계약:** `마을 공격력`에는 마을에서 음식·일시 버프 없이 확인한 **상태창 완성값**을 입력한다. 전설 패션, 동행 펫, 인장, 장착 룬의 고정 능력치는 이미 상태창에 포함되므로 다시 더하지 않는다. 적용 공격력은 `마을 공격력 × (1 + 선택 룬의 상시 공격력 증가율 합계 + 인챈트 공격력 증가율)`로 계산한다.

## 1. 최신 공통 측정스펙과 산식 검증

다섯 비식별 기준 기록의 측정스펙은 공격력 58,268, 치명타 8,688, 추가타 2,520, 강타 강화 3,980, 연타 강화 3,644, 스킬 위력 2,650, 빠른 공격 2,109, 빠른 스킬 2,158, 궁극기 1,682로 일치한다. 사용자가 제공한 인게임 마을 상태창 공격력은 60,607이며, 이 값은 전설 패션과 동행 펫을 포함한 완성 상태값으로 사용한다.

선택 룬의 상시 공격력 증가율은 타오르는 영광 23.5%, 잊힌 맹약 15%, 아귀 15%, 별바라기 14%로 합계 67.5%이다. 인챈트 증가율 6.8%를 더하면 적용 공격력은 다음과 같이 고정된다.

```text
60,607 × (1 + 0.675 + 0.068) = 105,638.001
```

| 검증 항목 | 값 | 계산 처리 |
|---|---:|---|
| 마을 상태창 공격력 | 60,607 | 입력값으로 직접 사용 |
| 룬 상시 공격력 증가율 | 67.5% | 초월·조건부 가동률을 다시 곱하지 않음 |
| 인챈트 공격력 증가율 | 6.8% | 스프레드시트의 `C10/100` 항목 |
| 최종 적용 공격력 | **105,638** | 회귀 테스트로 고정 |
| 인장 고정 공격력·능력치 환산 | +1,600 / +1,125 | 상태창 포함값으로 간주하여 재가산하지 않음 |
| 엠블럼 추가 공격력·밤의 축복 | 12.0% / 3.75% | 전투·장비 상태 중복 방지를 위해 적용 공격력에는 재가산하지 않음 |

## 2. 딜사이클 모델 보정

전승강은 `1-1 3 4 2-2 2 3 5 (444) 2`를 사용하며, 괄호의 `444`는 추가 스킬 발동 확률에 따른 설명용 표기이므로 실행 토큰으로 중복 계산하지 않는다. 승천 소닉 피스트의 추가 3타 확률과 강격 섬머솔트의 압축된 동작을 분리해 처리했다.

실제 전승강 기록에서 강격 섬머솔트는 119초 동안 23회 관측된다.[3] 기존 1초 기본 시전 시간은 압축된 3단계 섬머솔트의 실전 모션을 과소평가해 DPS를 과대산정했다. 기본 시전 시간을 2초로 정정한 뒤 전승강 3개 기록 평균과 계산 결과의 편차는 1.76%가 됐다.

## 3. 최신 5개 기록의 결과

단일 전투 기록은 추가 스킬 발동, 치명타, 전투 중 버프 유지 시간에 따라 변동한다. 따라서 동일한 측정스펙에서 하나의 고정 딜사이클로 산출한 값은 각 기록의 단일 결과보다 **동일 세팅 반복 측정의 평균값**과 비교하는 것이 타당하다. 현재 모델은 다섯 기록 평균에서 0.31%, 전승강 세 기록 평균에서 1.76% 편차로 수렴한다.

## 4. 회귀 방지 조치

`src/utils/calculator.coverage.test.js`는 60,607 입력값, 룬 증가율 67.5%, 인챈트 6.8%, 적용 공격력 105,638을 고정하는 회귀 테스트를 포함한다. 이 테스트는 인장·특수 보석·룬 고정 공격력·밤의 흔적·밤의 축복이 상태창 완성값에 중복 가산되는 변경을 차단한다.

`src/utils/skillMdParser.coverage.test.js`는 강격 섬머솔트의 마크다운에 명시적인 시전 시간이 없을 때 기본 시전 시간이 2초가 되는지를 검증한다. `scripts/compare_latest_reference_presets.mjs`는 다섯 예시 프리셋의 실전 DPS, 계산 DPS, 적용 공격력 및 세부 공격력 구성을 `results/latest_reference_preset_comparison.json`으로 갱신한다.
