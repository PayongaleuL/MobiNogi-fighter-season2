# 함선 허수아비 외부 DPS 기준 대조 검증

**검증일:** 2026-08-12 KST
**검증 대상:** `mobi-score.com` 전투 기록 4건과 현재 DPS 엔진
**판정 범위:** 외부 기록의 측정스펙을 현재 계산기 입력으로 정규화해, 스탯·룬·세공·스탠스가 손실 없이 반영되는지 확인합니다. 외부 실전 로그의 절대 DPS를 현재 고정 딜사이클 모델의 무조건적인 정답값으로 간주하지 않습니다.

> **중요한 입력 계약:** 외부 측정스펙의 `공격력`은 룬 등 장비 효과가 반영된 최종 상태값일 수 있습니다. 현재 계산기는 마을 공격력에 선택 룬·인장·조건부 효과를 추가 계산하므로, 외부의 최종 공격력을 그대로 `마을 공격력` 필드에 넣고 동일 룬을 장착하면 중복 가산됩니다. 아래 비교에서는 적용 공격력이 외부 측정스펙과 일치하도록 원시 마을 공격력을 역산했습니다.

## 3. 회귀 방지 조치

`src/utils/referenceProfiles.test.js`는 네 측정스펙 fixture를 고정합니다. 이 테스트는 각 프로필의 룬 데이터 존재 여부, 외부 최종 공격력과 계산 적용 공격력의 일치, 유한한 양수 DPS, 치명타·추가타·사이클 시간의 정상 범위를 검증합니다. 이 검증은 향후 룬 데이터, 세공 처리, 공격력 합산 또는 스탠스 로직이 외부 기준 프로필을 깨뜨릴 경우 즉시 탐지합니다.

절대 DPS 오차를 품질 게이트로 만들려면 우선 현재 계산기에 없는 입력을 제품 계약으로 추가해야 합니다. 필수 후보는 **룬 초월 단계**, **각 스킬 개조 단계**, **달의 인장 세부 세팅**, **버프별 가동률과 계수**, **로그 기반 실제 딜사이클**입니다. 이 정보가 확보되면 기록별 허용 오차를 사전에 합의한 골든 테스트로 승격합니다.
