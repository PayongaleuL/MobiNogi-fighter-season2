# 시안형 가로 레이아웃 시각 검토

초광폭(2560px) 캡처에서 종합 계산기는 좌측 필수 입력과 우측 결과·룬 작업공간이 동시에 노출되는 2열 구성을 확인했다. 실전 DPS 결과는 우측 상단에 유지되며, 룬 세팅과 세부 연산은 그 아래에 배치된다. 일반 데스크톱 폭에서는 입력 카드의 가독성을 위해 3열 이하로 축소하고, 초광폭에서만 4열·5열을 활용하도록 조정했다.

보석 세공실은 무기와 장신구를 가로로 나란히 두고, 나머지 장비군을 3열 블록으로 이어지는 12열 레이아웃으로 구성했다. 화면 폭이 줄어들면 기존 반응형 규칙에 따라 열 수가 감소하며 가로 넘침은 발생하지 않았다.

검증 스크립트는 2560px·1440px·390px에서 수평 넘침이 없고, DPS가 능력치 입력 변경에 따라 갱신되며, 보석 탭·테마 전환이 정상 동작하는 것을 확인했다.
