# P2-C 현행 대상·마도저항·로그 기반 근사 보정 계약

## 구현 범위

P2-C는 시즌2 미출시 대상인 `어비스 지옥2`를 전투 대상 목록에서 제거하고, 현행 룬다 어비스 매우 어려움 3종과 카브락 입문을 추가한다. 필요 마도저항·마도압력은 넥슨 공식 난이도 표를 사용한다.[1] [2] 방어도와 치명타저항은 공식 공개 수치가 아니므로, 현재 UI는 기존 함께하기 기록 9건을 현재 계산 코어·상태창·지정 딜사이클에 대입한 **P2-B 로그 기반 근사치**를 유지한다. 이후 수집한 혼자하기 1인 로그는 별도 후보 분석을 수행했지만, 인스턴스·상태창·전투 조건을 충분히 통제한 반복 표본이 아니므로 대상 데이터에 적용하지 않는다.

> **주의:** 아래 방어도·치명타저항은 공식 보스 스탯이 아니다. 표본 수가 적고 장비 제거가 여러 전투 변수를 동시에 바꾸므로, 모든 값은 `낮은 신뢰도`로 표시한다. 계산기는 근사 출력에 쓰되, UI·데이터·문서에서 공식 마도저항 수치와 명확히 분리한다.

> **혼자하기 후보 검증:** 보스룸 전용 평타·스킬 로그를 각 대상 1건씩 추가로 대조했다. 대상 템플릿 ID와 최대 체력은 함께하기 기록과 달랐으나, 방어도 후보와 치명타저항 후보를 독립 반복으로 교차 검증하지 못했다. 따라서 혼자하기 전용 대상·보정값은 **미확정**이며 현재 목록·수치를 변경하지 않는다. 상세는 [신규 1인 로그 후보 분석](../results/new_private_log_candidate_estimates.md)을 참조한다.

훈련 대상인 함선·티르코네일 허수아비는 기존 계산기 기준 방어도 30, 치명타저항 0을 유지한다. 이는 현행 보스의 사실값이 아니라 기존 참조 프리셋을 위한 훈련 기준값이다.

## 로그 근사 방법과 어비스 목록 판정

분석기는 각 공개 로그의 상태창 공격력·마도저항·치명타·강타 강화·연타 강화·콤보 강화·스킬 위력·광역 강화·추가타·빠른 공격·빠른 스킬·궁극기를 현 계산 코어의 입력에 매핑한다. 사용자 지정 조건인 `깊어지는 어둠 최종피해 +4.7%`, 흐릿한 형상 70%, 타오르는 영광 13%, 평상시 `1342235(444)2`, 궁극기 `445445445`를 고정한다.

방어도는 방어도 0 기준 모델 DPS와 기록된 대상 DPS의 비율로부터 `armor = 10,328 × (modelAtArmor0 / observed - 1)`을 사용해 역산한다. 무방비 직접피해 비중은 코어의 무방비 배율에 맞춰 시간 비중으로 환산한다. 치명타저항은 보스 저항 전 계산 확률과 실제 대상 직접 적중 치명률의 차이로 구하며, 로그상 차이가 음수인 경우에는 보스 저항이 음수가 될 수 없으므로 0으로 절단한다.

부트스트랩 80% 범위는 실제 로그 표본을 고정 시드로 재표본화한 중앙값의 10~90 분위다. 표본이 2~3건이므로 엄밀한 통계적 신뢰구간이 아니라 **근사치의 불안정성을 드러내는 범위**다. 상세 입력·로그별 후보·제외 한계는 [P2-B 근사 보정 분석](../results/p2b_calibrated_target_estimates.md)에 보존한다.

룬다 어비스 3종은 공식 필요 마도저항과 마도압력은 같지만, 기존 함께하기 로그 근사 방어도 범위의 공통 교집합이 없고 공통 방어도 적용 시 최대 방어계수 잔차가 35.7%였다. 신규 혼자하기 후보도 각 보스 1회에 그쳐 이 결론을 뒤집을 근거가 되지 못했다. 따라서 사용자의 “같다고 판단하면 목록 축소” 조건을 충족하지 못했으므로 **전투 대상 목록은 칼드레드·데스펠·테로사 3개를 개별로 유지**한다. 어비스 잡몹방과 보스룸의 방어도·치명타저항 차이는 보스룸 평타 기록만 존재하므로 미확정이다.

## 마도저항 입력 계약

> **마도저항 입력값은 장비와 선택 룬이 반영된 인게임 상태창 완료값이다.** 계산 코어는 선택 룬의 고정 마도저항을 다시 더하지 않는다.

이 계약은 공격력 완료값의 중복 가산 방지 원칙과 동일하다. 이전 결과 객체의 `totalResist`는 선택 룬에서 읽은 마도저항 합계라는 하위 호환 필드로 유지하며, 실제 마도저항 보정에 쓰는 입력은 `totalMagicResistance`와 `magicResistanceEffect`로 명시한다.

## DPS 반영 범위

넥슨 공식 가이드는 마도저항이 마도압력보다 낮으면 주는 피해가 감소하고 받는 피해가 증가하며, 같거나 높으면 페널티가 없고, 초과하면 적에게 입히는 최종 피해량이 증가한다고 설명한다. 초과 보정은 체감 곡선이고 최대 한도는 50%이나, 연속 함수와 미달 피해의 정량 계수는 공개하지 않는다.[3]

따라서 계산기는 공개된 초과 예시점만 적용한다. 인접 예시점 사이는 선형 보간하며, 8,000 초과 영역은 공개 연속식이 없어 마지막 공식 예시값 37.5%로 고정한다. 공식이 밝힌 최대 50%를 임의의 함수로 조기에 도달시키지 않기 위한 보수적 처리다. 미달 상태는 화면에 표시하지만 정량 DPS 페널티를 임의 적용하지 않는다.

| 마도저항 초과분 | 최종피해 증가 | 계산기 처리 |
| ---: | ---: | --- |
| 0 | 0.0% | 공식 기준점 |
| 500 | 4.1% | 공식 기준점 |
| 1,000 | 7.9% | 공식 기준점 |
| 2,000 | 14.6% | 공식 기준점 |
| 4,000 | 25.0% | 공식 기준점 |
| 8,000 이상 | 37.5% 고정 | 마지막 공개 예시 이후의 비공개 연속식은 추정하지 않음 |

최종 DPS 산식에서는 대상 방어 계수와 치명타저항을 기존 해당 위치에 각각 한 번만 적용하고, 그 뒤 기존 최종피해 항목과 `magicResistanceEffect.finalDamageMultiplier`를 한 번만 곱한다. 예를 들어 카브락 입문에서 마도저항 4,500은 마도압력 2,500보다 2,000 높으므로, 로그 근사 방어도 7,203이 적용된 최종 DPS에 `1.146`을 추가 적용한다.

## UI 및 검증

기본 스펙에는 `마도저항` 숫자 입력과 슬라이더가 있다. 전투 패널은 대상별 필요 마도저항·마도압력과 함께 적용 방어도·치명타저항, 로그 표본 수, 방어도 범위, 낮은 신뢰도 안내를 표시한다. 실전 DPS 요약도 실제로 적용한 방어도·치명타저항을 별도 지표로 표시한다. 자동 UX 게이트는 현행 대상 4개, 카브락 근사 보정 안내, 마도저항 2,500→4,500에 따른 +14.6% 변화를 검사한다.
