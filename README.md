# 마비노기 모바일 시즌2 격투가 DPS 계산기

[공개 계산기](https://payongaleul.github.io/MobiNogi-fighter-season2/)는 **마비노기 모바일 시즌2 격투가**의 현재 입력값을 기반으로 실전 가중 DPS를 계산하는 정적 웹 애플리케이션입니다. React·Vite 기반으로 브라우저에서 동작하며, 서버·인증·외부 비밀을 사용하지 않고 GitHub Pages에 배포됩니다.

> 이 프로젝트는 저장된 DPS를 재표시하지 않습니다. 마을 상태창, 룬·초월·세공·인장, 전투 대상, 마도저항, 조건부 가동률, 스킬 스탠스, 딜사이클을 입력으로 받아 매번 다시 계산합니다. 정상·궁극기 사이클이 비었거나 해석되지 않으면 기본 사이클을 대입하지 않고 해당 상태를 **0 DPS**로 처리합니다.

| 실전 DPS | 마을 공격력·치명타·강타/연타/콤보/스킬/광역/추가타 스탯, 인챈트, 세공, 인장, 시즌 패시브, 스킬 스탠스와 딜사이클을 결합한 계산 |

## 입력과 계산 계약

### 상태창 완료값 원칙

마을 공격력은 음식·일시 버프가 없는 인게임 상태창의 완성값입니다. 전설 패션 세트, 동행 펫, 달의 인장, 장착 룬의 **고정 공격력·고정 능력치**가 상태창에 이미 포함되었다면 계산 코어가 다시 더하지 않습니다.

적용 공격력은 다음 계약을 사용합니다.

```text
적용 공격력 = 마을 공격력 × (1 + 선택 룬의 상시 공격력% 합계 + 인챈트 공격력%)
```

상시 공격력%에는 조건부 가동률이나 초월 배율을 다시 곱하지 않습니다. 조건부 공격력 증가는 별도 효과 ID와 가동률을 가진 `조건부공증%`로 모델링합니다. 기본 가동률은 **흐릿한 형상 70%**, **타오르는 영광 13%**이며, 사용자 입력으로 조정할 수 있습니다.

마도저항도 장비와 장착 룬이 반영된 **상태창 완료값**입니다. 선택 룬의 고정 마도저항을 코어가 다시 합산하지 않아 중복 가산을 막습니다.

### 딜사이클과 연속 인스턴스

새 입력 문법은 같은 번호의 스킬을 연속으로 적었을 때 첫 번째 `1`을 `1-1`, 다음 `1`을 `1-2`처럼 순차 정규화합니다. 기존 저장 프리셋은 `legacy-v1` 문법으로 보존하여 과거 비교값이 임의로 바뀌지 않게 합니다. 강격 섬머솔트의 기본 시전 시간은 2초이며, 승천 소닉 피스트의 기대 시전 시간은 2.584초입니다.

## 현행 전투 대상과 보정 범위

필요 마도저항·마도압력은 넥슨 공식 난이도 표를 사용합니다.[1] [2] 방어도·치명타저항은 공식 공개 수치가 없으므로, 아래 값은 사용자 제공 공개 전투 기록 9건을 현재 코어·상태창·지정 딜사이클에 재입력한 **P2-B 로그 기반 근사치**입니다. 공식 스탯으로 해석하면 안 되며, 계산기와 UI에서 `낮은 신뢰도`로 명시합니다.

| 대상 | 필요 마도저항 | 마도압력 | 적용 방어도 | 방어도 80% 근사 범위 | 적용 치명타저항 | 로그 표본 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 함선 허수아비 | 0 | 0 | 30 | 훈련 기준값 | 0.0% | 해당 없음 |
| 티르코네일 허수아비 | 0 | 0 | 30 | 훈련 기준값 | 0.0% | 해당 없음 |
| 칼드레드 · 허상의 정박지 매우 어려움 | 2,200 | 2,700 | 8,408 | 6,561–10,255 | 0.0% | 2 |
| 데스펠 · 광기의 동굴 매우 어려움 | 2,200 | 2,700 | 17,125 | 15,646–18,605 | 0.0% | 2 |
| 테로사 · 흩어진 물길 매우 어려움 | 2,200 | 2,700 | 18,967 | 16,261–21,674 | 0.0% | 2 |
| 카브락 · 입문 | 2,000 | 2,500 | 7,203 | 7,039–9,542 | 0.0% | 3 |

룬다 어비스 매우 어려움 3종은 필요 마도저항과 마도압력은 같지만, 로그 기반 공통 방어도 모델의 최대 방어계수 잔차가 **35.7%**이고 개별 근사 범위의 공통 교집합도 없었습니다. 따라서 세 보스를 하나의 `매우 어려움` 선택지로 축소하지 않고, 전투 조건에서 각각 분리해 둡니다.

### 마도저항 보정

넥슨 가이드는 마도저항이 마도압력보다 낮으면 주는 피해가 감소하고 받는 피해가 증가하며, 같거나 높으면 페널티가 없고, 초과 시 적에게 입히는 최종피해가 증가한다고 안내합니다.[3] 공개된 초과 예시점만 아래와 같이 반영합니다. 미달 시 정량 피해 계수와 초과분의 완전한 연속 함수는 공개되지 않았으므로 임의로 추정하지 않습니다.

| 마도저항 초과분 | 최종피해 증가 | 계산기 처리 |
| ---: | ---: | --- |
| 0 | 0.0% | 공식 기준점 |
| 500 | 4.1% | 공식 예시점 |
| 1,000 | 7.9% | 공식 예시점 |
| 2,000 | 14.6% | 공식 예시점 |
| 4,000 | 25.0% | 공식 예시점 |
| 8,000 이상 | 37.5% 고정 | 이후 비공개 연속식은 추정하지 않음 |

예를 들어 카브락 입문에서 상태창 마도저항이 4,500이면 마도압력 2,500보다 2,000 높으므로, 대상 방어도·치명타저항을 반영한 결과에 최종피해 배율 `1.146`을 한 번 적용합니다.

## 계산 구조

계산과 화면 렌더링은 논리적으로 분리돼 있습니다.

| 계층 | 주요 경로 | 책임 |
| --- | --- | --- |
| 순수 계산 코어 | `src/core/` | DPS, 보석, 인장, 마도저항, 대상 보정. React·DOM·localStorage 의존 없음 |
| 애플리케이션 어댑터 | `src/adapters/` | 룬 평탄화, 세공 집계, 스킬 원문 파싱, 입력 조립, 기존 저장값 호환 |
| UI·데이터 | `src/components/`, `src/data/` | React 입력·표시, 정적 룬/대상 데이터, 접근성·반응형 UI |

계산 결과는 적용 공격력, 마도저항/압력, 마도저항 최종피해, 대상 방어도, 대상 치명타저항, 룬 공격력 가산, 치명타·추가타 확률을 함께 보여 줍니다. 렌더러는 계산식을 직접 수행하지 않고 어댑터의 결과만 소비합니다.

## 로컬 실행과 품질 검증

### 실행

```bash
npm install
npm run dev
```

기본 개발 주소는 `http://localhost:5173/MobiNogi-fighter-season2/`입니다.

### 필수 품질 관문

계산 엔진, 룬 파서, 인장·보석 계산, 대상 데이터 또는 UI를 바꾸면 다음을 순서대로 실행합니다.

```bash
npm run lint
npm run test:coverage
npm run build
node scripts/compare_latest_reference_presets.mjs
node scripts/ux-ui-check.mjs
npm run test:e2e
```

커버리지 임계값은 Statements·Branches·Functions·Lines 각각 **95%**입니다. 최근 P2-B/P2-C 검증에서는 101개 테스트가 통과했고, Statements 99.09%, Branches 96.25%, Functions 100%, Lines 99.50%를 기록했습니다. 5개 기준 프리셋은 모두 실전 평균 대비 ±10% 안에 있으며 평균 절대 편차는 3.93%입니다.

| 검증 레이어 | 목적 |
| --- | --- |
| `npm run lint` | 정적 오류·신규 경고 차단 |
| `npm run test:coverage` | 코어·파서·데이터·UI의 회귀 및 95% 커버리지 기준 확인 |
| `npm run build` | GitHub Pages용 Vite 프로덕션 빌드 확인 |
| `compare_latest_reference_presets` | 허수아비 기준 프리셋 5건의 모델 편차 확인 |
| `ux-ui-check` | 2560×1440, 1440×1050, 390×844에서 대상·마도저항·오버플로·접근성 확인 |
| `npm run test:e2e` | 데스크톱·모바일 렌더링, 입력 변경 시 DPS 재계산, 브라우저 오류 확인 |

## 재현 가능한 로그 근사 분석과 개인정보

`scripts/analyze_p2b_calibrated_targets.mjs`는 로컬의 `results/p2b_raw_logs/`에 보관한 원본 공개 기록을 읽어 대상별 방어도·치명타저항 후보, 부트스트랩 80% 근사 범위, 룬다 어비스 공통 모델 판정을 생성합니다.

```bash
node scripts/analyze_p2b_calibrated_targets.mjs
```

원본 기록 JSON에는 개인 전투 상세와 장비 정보가 포함될 수 있으므로 Git에서 제외합니다. 저장소에는 재현 스크립트와 익명화된 분석 결과만 보관합니다. 분석 방법·로그별 후보·한계는 [P2-B 로그 기반 근사 보정 분석](results/p2b_calibrated_target_estimates.md)에서, 현행 대상·마도저항 데이터 계약은 [P2-C 구현 계약](docs/P2C_CURRENT_TARGETS_AND_MAGIC_RESISTANCE.md)에서 확인할 수 있습니다.

## 배포

`main` 병합 후 GitHub Actions가 린트·커버리지·빌드·E2E를 실행하고, 성공한 정적 산출물만 GitHub Pages에 배포합니다. 공개 배포본의 최신 화면 검증 기록은 [P2-C 렌더링 검증 기록](results/p2c_render_verification.md)에 보존합니다.
